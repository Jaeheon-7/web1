# web1

생활코딩 WEB1 실습 사이트입니다.

## 페이지

- `index.html`, `1.html`, `2.html`, `3.html` — HTML 실습 문서
- `card.html` — **명함 스캐너**. 명함 사진을 올리면 브라우저 안에서 글자를 읽어
  이름·회사·직함·전화·이메일·주소를 뽑고, 확인 후 vCard(.vcf)나 CSV로 내려받아
  휴대폰 주소록이나 구글 주소록에 넣을 수 있습니다.

## 명함 스캐너 메모

- 글자 인식은 Tesseract.js를 CDN에서 불러와 **브라우저 안에서** 처리합니다.
  사진이 서버로 올라가지 않고, 이 저장소에도 서버가 없습니다.
- 한국어 학습 데이터를 처음 한 번 내려받기 때문에 첫 인식은 느립니다.
- 브라우저는 웹페이지가 주소록에 직접 쓰는 것을 허용하지 않습니다.
  그래서 마지막 저장은 사용자가 .vcf 파일을 여는 한 번의 동작으로 끝냅니다.
- 인식 엔진을 못 불러와도 입력 칸에 직접 적어 vCard를 만들 수 있습니다.
